NuLattice Documentation
=======================

NuLattice is a framework for ab initio nuclear lattice effective field theory (NLEFT) calculations. It provides solvers for Hartree-Fock (HF), Coupled Cluster (CCSD), In-Medium Similarity Renormalization Group (IMSRG), and Full Configuration Interaction (FCI).
